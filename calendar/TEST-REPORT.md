# گزارش آزمون نسخه v24

تاریخ اجرای بررسی: ۲۰۲۶-۱۰-۲۰

## آزمون‌های انجام‌شده

| آزمون | نتیجه | جزئیات |
|---|---|---|
| بررسی نحوی فایل‌های JavaScript برنامه (به‌جز vendor) | موفق | `node --check` برای تمام فایل‌های JS برنامه اجرا شد. |
| بررسی نحوی `sw.js` | موفق | `node --check sw.js` |
| اعتبارسنجی `manifest.json` | موفق | فایل با JSON parser پایتون بارگذاری شد. |
| بررسی ساختار ZIP ورودی | موفق | ZIP قابل‌خواندن بود و ۴۲ فایل داشت. |
| بازبینی تغییرات صفحه‌بندی A4 | ایستا | جریان خطوط مناسبت و یادداشت، ظرفیت صفحهٔ اول و صفحه‌های ادامه بررسی شد؛ آزمون Canvas در مرورگر اجرا نشده است. |

## آزمون‌های انجام‌نشده

- اجرای واقعی روی Chromium/Firefox یا گوشی اندرویدی: محیط مرورگر خودکار در دسترس نبود.
- آزمون دیداری PNG در کیفیت‌های ۱×، ۲× و ۳×.
- اعتبارسنجی رندر و ناحیه‌های کلیک SVG و HTML.
- تولید ZIP چندصفحه‌ای و گروهی در مرورگر، آزمون لغو، و بررسی خطاهای حافظه.
- آزمون آفلاین، نصب PWA، پاک‌سازی کش در مرورگر واقعی.
- آزمون کامل تبدیل تاریخ شمسی/میلادی/قمری و تطبیق با منبع رسمی.
- آزمون ورودی‌های بسیار بلند، ایموجی‌های ترکیبی و تمام حالت‌های نیم‌فاصله در Canvas واقعی.

## نتیجه
بررسی نحوی و JSON موفق است، اما به‌دلیل اجرا نشدن آزمون مرورگر، این گزارش ادعای تأیید کامل معیارهای انتشار را ندارد. پیش از انتشار عمومی، دست‌کم آزمون دستی A4 با متن کوتاه، چندصفحه‌ای، مناسبت چندخطی و متن بسیار بلند و سپس کنترل PNG/ZIP انجام شود.
