# تولید کارت تقویم روزانه

ابزار ساخت کارت تقویم روزانه با تاریخ شمسی، قمری و میلادی، ذکر روز، عکس، لوگو و QR کد.
بدون سرور و بدون نصب؛ فقط چند فایل ثابت.

## ساختار پوشه‌ها
```
calendar/
├─ index.html              صفحهٔ اصلی
├─ manifest.json           اطلاعات نصب روی گوشی (PWA)
├─ sw.js                   ذخیره برای استفادهٔ آفلاین
├─ css/
│  └─ style.css            ظاهر صفحه
├─ js/
│  ├─ registry.js          ثبت قالب‌ها و انتخاب قالب پیش‌فرض
│  ├─ shared.js            آیکن‌ها و ابزارهای مشترک نقاشی
│  ├─ app.js               منطق برنامه (تاریخ، عکس، خروجی‌ها)
│  ├─ accordion.js         منوهای کشویی تنظیمات
│  └─ templates/           ← هر قالب یک فایل جدا
│     ├─ royal.js          سلطنتی نورانی (پیش‌فرض)
│     ├─ classic.js        کلاسیک سبز و طلایی
│     ├─ light.js          مدرن روشن
│     ├─ blackgold.js      مشکی و طلایی
│     └─ ribbon.js         روبان طلایی
└─ assets/
   └─ icons/               آیکن‌های برنامه
```

## امکانات
- ۵ قالب آماده، خروجی PNG، ZIP (چند روز پشت سر هم)، HTML و SVG با لینک کلیک‌پذیر
- زوم و جابجایی عکس، ویرایش ذکر هر روز هفته
- قابل نصب روی موبایل و کار کردن بدون اینترنت (پس از یک‌بار باز شدن)

## افزودن قالب جدید
1. یکی از فایل‌های `js/templates/` را کپی کنید و اسمش را عوض کنید (مثلاً `mylook.js`).
2. داخلش `id`، `label` (نام در لیست)، `swatch` (رنگ پیش‌نمایش) و `style` را عوض کنید و تابع نقاشی را بنویسید.
3. در `index.html` یک خط اضافه کنید: `<script src="js/templates/mylook.js"></script>` (قبل از `app.js`).
4. در `sw.js` مسیر فایل را به فهرست `CORE` اضافه کنید و عدد نسخه را بالا ببرید.

قالب خودش به لیست و کارت‌های انتخاب اضافه می‌شود؛ به جای دیگری دست نزنید.

قالب پیش‌فرض را در `js/registry.js` (`DEFAULT_TEMPLATE`) عوض کنید.

## انتشار با GitHub Pages
1. همهٔ فایل‌ها و پوشه‌ها را داخل پوشهٔ `calendar` مخزن بگذارید و commit کنید.
2. در مخزن: **Settings ← Pages**، منبع را شاخهٔ `main` و پوشهٔ `/ (root)` بگذارید.
3. آدرس برنامه: `https://diyareghadamgah.github.io/diyar-widgets/calendar/`

## تغییر مقادیر پیش‌فرض
در `index.html` مقدار `value` این فیلدها را عوض کنید: `id="channel"` (نام کانال)، `id="channelUrl"` (لینک کانال) و `id="phone"` (شماره تماس).

## بعد از هر تغییر
اگر هر فایلی را عوض کردید، عدد `diyar-calendar-v3` را در `sw.js` بالا ببرید (مثلاً `v4`) تا کاربران نسخهٔ جدید را بگیرند.

## نیازمندی‌ها
اولین بار به اینترنت نیاز است (فونت Vazirmatn، کتابخانهٔ JSZip و QR از CDN بارگذاری می‌شوند)؛ بعد از آن در کش مرورگر می‌ماند.
