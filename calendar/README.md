# تقویم روزانه دیار قدمگاه — نسخه v25

ابزار سمت‌کاربر برای تولید کارت تقویم با HTML، CSS و JavaScript ساده؛ بدون نیاز به فرایند build.

## اجرا
1. کل پوشهٔ `calendar` را در یک وب‌سرور استاتیک قرار دهید.
2. برای اجرای محلی، در پوشهٔ `calendar` دستور `python3 -m http.server 8000` را اجرا کنید.
3. در مرورگر به `http://localhost:8000/` بروید. اجرای مستقیم با `file://` برای Service Worker و بعضی امکانات مناسب نیست.

## امکانات موجود
- قالب‌های عمومی و مناسبتی، یادداشت، تصویر، لوگو، ذکر روز، QR و لینک کلیک‌پذیر.
- خروجی PNG، SVG، HTML، متن آمادهٔ انتشار و ZIP گروهی.
- تنظیمات و پشتیبان JSON، مناسبت شخصی و اصلاح دستی تاریخ قمری.
- قالب «یادداشت A4» با صفحه‌بندی چندصفحه‌ای.
- **قالب جدید «اطلاعیه رسمی 📢»** با ظاهر تابلوی اعلانات و صفحه‌بندی خودکار.
- کتابخانه‌های JSZip و QR به‌صورت محلی.

## تغییرات v25
- **A1:** Service Worker با پیام `SKIP_WAITING` و اسکریپت `updatefound` در `index.html` برای به‌روزرسانی سریع.
- **A2:** ساده‌سازی منطق تشخیص قالب چندصفحه‌ای در ناوبری.
- **A3:** محدودیت `maxlength` روی `note` (۲۰٬۰۰۰) و `customEventText` (۳٬۰۰۰) + شمارندهٔ متن + `sanitize` هوشمند (کوتاه‌سازی به‌جای رد کامل).
- **A4:** بررسی `shared.js` (بدون مشکل).
- **A5:** بهبود `drawEventsBadge` — چندانتخابی با `wrapText` به‌جای برش تک‌خطی ۷۰ کاراکتری.
- **A6:** افزودن `title`، `role="button"`، `tabindex="0"` و پشتیبانی کیبورد (`Enter`/`Space`) به کارت‌های قالب.
- **B1:** به‌روزرسانی README (همین فایل).
- **B2:** هشدار و تأیید در زمان خروجی اگر متن > ۱۰ صفحه A4/اطلاعیه است.
- **B3:** دکمهٔ «پیش‌نمایش کامل» در نوار ابزار برای بازکردن کارت در تب جدید.
- **جدید:** قالب «اطلاعیه رسمی 📢» (`js/templates/announcement.js`).
- کش Service Worker به `diyar-calendar-v25b` ارتقا یافت.

## چک‌لیست آزمون دستی (پیشنهاد می‌شود قبل از انتشار)
- [ ] بازکردن صفحه، بررسی کنسول (بدون خطا).
- [ ] انتخاب همهٔ قالب‌ها (۲۷ قالب) بدون خطا.
- [ ] ورود متن کوتاه + قالب A4 → ۱ صفحه.
- [ ] ورود متن بلند (منشور) + قالب A4 → ۲+ صفحه + نوار ناوبری.
- [ ] ورود متن بلند + قالب «اطلاعیه رسمی» → ۲+ صفحه + امضا در صفحهٔ آخر.
- [ ] ورود > ۲۰٬۰۰۰ کاراکتر → `maxlength` مانع شود.
- [ ] ثبت مناسبت کاربر + جایگزینی → برچسب «مناسبت روز» حذف شود.
- [ ] دریافت/بارگذاری فایل تنظیمات JSON.
- [ ] بارگذاری فایل JSON خراب → پیام خطای فارسی، بدون ازدست‌رفتن تنظیمات.
- [ ] دانلود PNG در A4 چندصفحه‌ای → ZIP.
- [ ] دانلود ZIP گروهی ۷ روز → ۷ فایل + گزارش.
- [ ] «پیش‌نمایش کامل» (دکمهٔ جدید) → تب جدید.
- [ ] آزمون آفلاین (بعد از بارگذاری اول).
- [ ] بررسی کش پس از انتشار (`caches.keys()` فقط `diyar-calendar-v25b`).

## انتشار و رفع مشکل کش
1. فایل‌های این پوشه را در مسیر انتشار پروژه جایگزین کنید.
2. پس از انتشار، صفحه را دوباره بارگذاری کنید و چند ثانیه برای فعال‌شدن Service Worker جدید فرصت بدهید.
3. اگر نسخهٔ قدیمی نمایش داده شد، در تنظیمات سایت مرورگر داده‌های سایت را پاک کنید یا از بخش Application/Storage گزینهٔ پاک‌کردن داده و کش سایت را اجرا کنید؛ سپس صفحه را دوباره باز کنید.
4. کش جدید در `sw.js` با نام `diyar-calendar-v25b` تعریف شده است؛ برای انتشار بعدی، نام کش را به نسخهٔ جدید ارتقا دهید.

## نکته دربارهٔ متن‌های بلند
- قالب «مناسبت روز» یک کارت با فضای محدود است. برای متن بلند یا خروجی چاپی کامل، قالب «یادداشت A4» یا «اطلاعیه رسمی 📢» را انتخاب کنید.
- در A4، مناسبت‌ها و متن یادداشت به‌صورت پیوسته بین صفحات تقسیم می‌شوند.
- در «اطلاعیه رسمی»، متن به‌صورت صفحه‌بندی خودکار با نوار عنوان (مگافون) و امضای پایانی در صفحهٔ آخر نمایش داده می‌شود.

## وابستگی‌ها و آفلاین
- JSZip و کتابخانهٔ QR محلی هستند.
- فونت Vazirmatn از منبع خارجی در CSS دریافت می‌شود؛ در اولین اجرای آفلاین تضمین نمی‌شود. برای آفلاین کامل باید فایل فونت مجاز به پروژه اضافه شود.
- داده‌های مناسبت در `js/events.js` و جدول اصلاح قمری در `js/hijri.js` قرار دارند.

## وضعیت آزمون
آزمون نحوی JavaScript (`node --check`) روی همهٔ فایل‌های JS انجام شده و موفق است. آزمون واقعی مرورگر، نمایش تصویری، نصب PWA و آزمون کامل تاریخ‌ها در این مرحله انجام نشده و باید توسط شما روی محیط واقعی انجام شود.
