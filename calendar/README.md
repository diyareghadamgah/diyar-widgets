# تولید کارت تقویم روزانه

ابزار ساخت کارت تقویم روزانه با تاریخ شمسی، قمری و میلادی، ذکر روز، عکس، لوگو و QR کد.
بدون سرور و بدون نصب؛ فقط یک صفحهٔ وب.

## امکانات
- ۵ قالب: سلطنتی نورانی، کلاسیک، مدرن روشن، مشکی و طلایی، روبان طلایی
- خروجی PNG، ZIP (چند روز پشت سر هم)، HTML و SVG با لینک کلیک‌پذیر
- زوم و جابجایی عکس (با ماوس یا لمس)، ویرایش ذکر هر روز هفته
- قابل نصب روی موبایل و کار کردن بدون اینترنت (پس از یک‌بار باز شدن)

## فایل‌ها
| فایل | کار |
|---|---|
| `index.html` | خود برنامه |
| `manifest.json` | اطلاعات نصب روی گوشی (PWA) |
| `sw.js` | ذخیرهٔ فایل‌ها برای استفادهٔ آفلاین |
| `icon-192.png`، `icon-512.png` | آیکن برنامه |

## انتشار با GitHub Pages
1. همهٔ فایل‌ها را داخل پوشهٔ `calendar` مخزن بگذارید و commit کنید.
2. در مخزن: **Settings ← Pages**، منبع را شاخهٔ `main` و پوشهٔ `/ (root)` بگذارید.
3. آدرس برنامه می‌شود: `https://diyareghadamgah.github.io/diyar-widgets/calendar/`

## تغییر مقادیر پیش‌فرض
در `index.html` مقدار `value` این فیلدها را عوض کنید: `id="channel"` (نام کانال)، `id="channelUrl"` (لینک کانال) و `id="phone"` (شماره تماس).

## بعد از هر تغییر
اگر `index.html` را عوض کردید، عدد `diyar-calendar-v1` را در `sw.js` بالا ببرید (مثلاً `v2`) تا کاربران نسخهٔ جدید را بگیرند.

## نیازمندی‌ها
اولین بار به اینترنت نیاز است (فونت Vazirmatn، کتابخانهٔ JSZip و QR از CDN بارگذاری می‌شوند)؛ بعد از آن در کش مرورگر می‌ماند.
