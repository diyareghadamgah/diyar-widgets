# دیار پلیر v1.3

نسخه حرفه‌ای Player دیار قدمگاه، ادامه مستقیم v1.2.

## تغییرات v1.3
- بهبود سازگاری شناسه فایل‌های شخصی در مرورگرهای مختلف
- مرتب‌سازی صحیح تاریخچه پخش؛ فایل‌های بدون سابقه دیگر بالای لیست نمی‌آیند
- کاهش ذخیره‌سازی غیرضروری وضعیت پخش در زمان `timeupdate`
- بروزرسانی Service Worker به v1.3
- دریافت `playlist.json` به‌صورت Network-first تا تغییرات GitHub Pages سریع‌تر دیده شوند
- حفظ fallback آفلاین برای playlist
- ساختار ZIP آماده برای استخراج مستقیم در `diyar-widgets/player/`

## امکانات موجود
- کتابخانه آنلاین و فایل‌های شخصی
- IndexedDB
- علاقه‌مندی، تاریخچه، صف پخش و جستجو
- فیلتر دسته‌بندی و مرتب‌سازی
- حذف فایل شخصی
- اشتراک‌گذاری/کپی لینک
- Shuffle / Repeat / Seek / Speed / Sleep Timer
- Visualizer با Web Audio API
- Media Session و PWA
- حالت روشن/تاریک و وضعیت آنلاین/آفلاین
