## کامپایل جاوا
`NaghmeStoragePlugin.java` و `MainActivity.java` در برابر **stubهای دست‌نویس** (که خودم از امضای APIهای Android/Capacitor نوشتم) با `javax.tools` کامپایل شدند و بدون خطا بودند. این فقط یعنی کد با فرض‌های من سازگار است؛ **با Android SDK و Capacitor واقعی کامپایل نشده** و ممکن است امضای واقعی یک API فرق داشته باشد.

## تست انجام‌نشده (صادقانه)
- **ساخت APK** (`./gradlew assembleDebug`)، **`npm install`** و **`npx cap add android`**: SDK، Gradle و اینترنت نبود. نسخه‌ی `^6.2.0` و قالب پروژه‌ی تولیدشده‌ی Capacitor آزمایش نشد؛ آزمون `setup-android.js` روی اسکلتی بود که از حافظه از قالب Capacitor 6 ساختم.
- **پایداری واقعی مجوز SAF** بعد از بستن برنامه و ریستارت گوشی، رفتار `ACTION_OPEN_DOCUMENT_TREE` در تولیدکننده‌های مختلف، سرعت `listAudio` روی ۳۷۷ یا ۵۰۰۰ فایل واقعی.
- **رفتار WebView**: پخش در پس‌زمینه/خاموشی صفحه (راه‌حل آزمایشی `MainActivity`)، اعلان و کنترل صفحه‌ی قفل، محدودیت حافظه‌ی Blob برای فایل‌های بزرگ، سهمیه‌ی IndexedDB.
- سرعت خواندن Base64 از پل Capacitor برای آرشیو واقعی (۲٫۲ گیگابایت).
- `MediaMetadataRetriever` روی فایل‌های خراب/غیر MP3 واقعی.
- گردش‌کار GitHub Actions (`.github-template/naghme-android.yml`).
- انتقال واقعی پشتیبان از PWA به APK روی دو مبدأ متفاوت (فقط منطق ادغام آزمایش شد).
- همه‌ی موارد آزمایش‌نشده‌ی نسخه‌های قبل (گوشی واقعی، پوشه‌ی واقعی، سقف حافظه، لینک اینترنتی واقعی، Firefox/Safari).
